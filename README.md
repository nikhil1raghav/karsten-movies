# Karsten Runquist Movie Recommendations

A single-page, searchable list of 638 films recommended by Karsten Runquist.

- `index.html` — the whole site (inline CSS/JS, no build step)
- Poster images are hotlinked from Amazon's IMDb CDN

## Local preview

Open `index.html` in a browser, or `python3 -m http.server`.

## Deploy

Hosted on Cloudflare Pages (static, no build command, output directory `/`).
